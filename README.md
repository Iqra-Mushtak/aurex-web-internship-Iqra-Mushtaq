## Task Description
Transformed the Week 1 semantic HTML developer profile into a responsive web portfolio using CSS3, Flexbox, and CSS Grid. The design focuses on clean visual hierarchy, smooth micro-interactions, cohesive typography, and mobile-friendly usability.

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
- Git & GitHub
- GitHub Pages (Hosting & Deployment)

## CSS Features & Layout Techniques
- **CSS Grid:** Applied in the Skills section using auto-fill responsive tracks (`repeat(auto-fill, minmax(...))`) for dynamic badge wrapping.
- **Flexbox:** Configured for sticky navigation, alignment of header elements, card layout containers, and the contact form.
- **Modern UI Styling:** Utilized CSS custom variables, glassmorphic effects (`backdrop-filter`), background mesh gradients, and pill-shaped badge elements.
- **Responsive Design:** Integrated CSS media queries (`768px` and `480px`) to guarantee clean layouts across Desktop, Tablet, and Mobile viewports.
